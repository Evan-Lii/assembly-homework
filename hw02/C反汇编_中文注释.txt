理解要点：
1. C 的两层 for 循环被翻译为初始化、比较、条件跳转和递增指令。
2. 编译器在本次 -O0 编译中使用 CMP/JLE，而没有使用 LOOP 指令。
3. putchar 调用通过 Windows C 运行库输出；DOS 汇编版使用 INT 21h/AH=02h。
4. EAX、ESP、EBP 是 32 位寄存器，与 DOS 版的 AX、SP、BP 位宽不同。
5. 若改动源码、编译选项或编译器，地址与指令可能改变，须重新提取和核对注释。
