# 作业 5：递归调用——斐波那契数列

输入 n（1≤n≤100），精确输出 F(n)。采用 F(0)=0、F(1)=1、F(n)=F(n−1)+F(n−2)。汇编与 C 均使用真正的递归调用，并对已计算结果进行记忆化缓存。

## 精确数值与递归

F(25) 已超过无符号 16 位范围，F(48) 超过无符号 32 位范围，F(94) 超过无符号 64 位范围。F(100) 有 21 位十进制数字，不能只用一个普通整数寄存器保存。

每个结果使用 21 个字节，每字节保存一个数值 0～9，低位在前。例如 55 保存为 5、5、0、…；21 字节可容纳 0～10²¹−1，足够保存本题所有结果。相加时从低位开始，每位最大 9+9+1=19，产生的进位仅为 0 或 1。输出时从最高非零位向最低位打印。

缓存 memo 共 101×21=2121 字节，位于数据段；ready[0]、ready[1] 和对应 F(0)、F(1) 预先初始化。计算未缓存的 F(n) 时：

1. 递归调用 Fib(n−1)，保存返回指针。
2. 再递归调用 Fib(n−2)。
3. 逐位相加并保存 memo[n]，设置 ready[n]=1。
4. 返回指向结果的 SI（C 版为返回指针 RAX）。

这仍是递归实现；缓存命中时直接返回。n=100 时无需展开指数数量的重复子问题，首次计算最多同时存在 100 层 Fib 调用。全部 n≤100 的计算只需 O(n×21) 次逐位处理。

## 寄存器约定与寻址

Fib 的输入 AX=n，内部允许 0～100；主程序只接受 1～100。输出 SI=&memo[n][0]。AX、BX、CX、DX、DI、BP 均保存恢复；SI 为明确约定的返回值，标志位不承诺保存。

过程用 PUSH BP / MOV BP,SP 建立本层栈帧，再保存 AX/BX/CX/DX/DI。本层原始 n 位于 SS:[BP−2]，两次子调用后仍可读取。第一次调用的 SI 指针再额外 PUSH，第二次调用返回后 POP 到 BX。父子调用各有独立的返回地址和寄存器保存区。

缓存寻址为 DS:OFFSET memo+n×21+digit；BP 用于栈局部访问时默认段为 SS。缓存位于数据段，递归调用不在每层栈帧中复制 21 字节结果。

## 栈大小结论

独立 STACK 段大小为 4096 字节，入口依次设置 SS 和 SP=1000h；MOV SS 后紧跟 MOV SP。栈从高地址向低地址增长，最低两字节保存 A55Ah 标记。

8086 近 CALL 压入 2 字节返回 IP，Fib 保存 6 个寄存器共 12 字节，每层合计 14 字节。第一次递归返回后，为第二次调用额外保存 2 字节结果指针。由于先完成 F(n−1)，第二次所需 F(n−2) 已缓存，不会形成另一条同样深的未计算分支。

n≥2 时，Fib 自身最深占用为 14×n+2 字节。n=100 为 1402 字节，测得最小 SP=1000h−057Ah=0A86h；返回后 SP=1000h，栈底 A55Ah 完好。n=4 的对应值为 58 字节、最低 SP=0FC6h。这两个数均来自真实 DEBUG 记录。

1402 字节指递归的近调用、寄存器及临时指针，不含 DOS/调试器内部中断处理开销；4096 字节还保留了余量，不能把该数当作整个系统的精确栈高水位。[调试记录](调试与学习记录.md)给出了逐次调用和返回的变化。

C 编译目标为 Windows x64，近 CALL 返回地址占 8 字节；本次 fib 每层分配 72 字节，加返回地址合计 80 字节，100 层约 8000 字节，另有 main 和运行库开销。链接时显式预留 1 MiB 线程栈，已核对 PE 头。不要把 C 和 8086 的栈帧大小混用。

## 运行和重新构建

汇编 EXE 为 16 位 DOS 程序，须在 DOSBox 中运行。假设仓库位于 D:/assembly-homework：

```text
mount c D:/assembly-homework
c:
cd hw05
FIB
```

MASM、LINK 已加入 DOSBox 的 PATH 后，在 hw05 目录执行：

```text
masm FIB.ASM;
link FIB.OBJ;
masm FIBREG.ASM;
link FIBREG.OBJ;
FIBREG
```

三份 INC 必须与 ASM 放在同一目录。自检使用与正式程序相同的 FIBDATA.INC 和 FIBPROC.INC。

C 版在 Windows x64 上运行 FIB_C.EXE。使用 Visual Studio 的 x64 Native Tools 命令提示符重建并导出反汇编：

```text
cl /nologo /TC /Od /Ob0 /W4 /MT /Fe:FIB_C.EXE FIB_C.c /link /INCREMENTAL:NO /STACK:1048576 /MAP:FIB_C.MAP
dumpbin /nologo /disasm FIB_C.EXE > C_FULL.TXT
```

编译器为 MSVC 19.51.36248。本次保留未优化递归调用便于观察；中文注释文件只截取三个用户函数，共 177 条指令，全部与最终 EXE 字节对应。修改代码、编译器或选项后，函数地址和栈帧可能变化，应重新提取并核对。
