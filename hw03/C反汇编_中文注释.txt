进入函数后按 i=1、total=0 初始化，重复 total+=i、++i，直到 i>n。

理解要点
1. sum_to 使用栈内局部变量保存 total，这与 SUM_STK.ASM 中的栈变量在概念上对应，位宽和栈帧布局不同。
2. C 的 for 循环被翻译为初始化、ADD、CMP、JBE 等指令，未使用 LOOP。
3. unsigned int 的比较使用无符号条件跳转；JBE 的含义是小于或等于。
4. C 使用 fgets 与 printf；DOS 汇编版使用 INT 21h 的 0Ah、09h、02h 功能。
5. 输入范围验证在 main 中完成，sum_to 接收已经验证过的 n。
6. 改动源代码、编译器或编译选项后，地址和指令可能变化，应重新提取并核对注释。
